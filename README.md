# wndr-stickers

Отдельный Telegram-бот, который делает стикеры для сообщества WNDR в стиле пака.
Самостоятельный процесс под launchd; Hermes-скилл существует только как
операционный sidecar и самим ботом не загружается.

WNDR Club — место, где мы вместе продвигаемся в важных областях жизни и
поддерживаем друг друга на пути. В основе — meta-skill действия: двигаться
вперёд, даже когда нет всех ответов; не ждать идеальных условий, а делать шаги
и собирать результаты. Стикерпак — язык этого движения, не просто мерч.

## Граница изоляции

- Runtime/state/output/logs живут только в `~/.wndr-stickers/`, вне Katya AI,
  Hermes, WORK/PERSONAL и Vault.
- SQLite — единственное durable-хранилище; shared Qdrant и Memory API не используются.
- Весь launchd-runtime запускается под macOS `sandbox-exec` с профилем `deploy/wndr-stickers.sb`: home Кати deny-by-default, разрешены только repo, `~/.wndr-stickers/` и `~/.codex/auth.json`.
- LaunchAgent выставляет `WNDR_RUNTIME_SANDBOX=1`; поэтому Codex не применяет вложенный `sandbox-exec` (macOS это запрещает), но всё равно получает временные `HOME`/`CODEX_HOME`, env allowlist и без user config/rules/sessions.
- При ручном запуске без `WNDR_RUNTIME_SANDBOX=1` Codex сам оборачивается в standalone `sandbox-exec`, запрещающий настоящий home.
- Telegram poller защищён file lock: второй процесс завершается до `getUpdates`.

## Суть подхода

Модель рисует **только плашку, без единой буквы**. Кириллицу впечатывает код
настоящим шрифтом. Два присланных гайда расходились именно здесь: первый просил
модель писать фразу самой, второй запрещал («на кириллице всегда брак»).
Выиграл второй — и правильно: теперь «объем» всегда с твёрдым знаком, «ё» не
подменяется на «е», а вопросительный знак стоит ровно тогда, когда он есть в
исходной фразе.

```
фраза
  ↓
модель рисует плашку на чёрном фоне, середина пустая
  ↓
заливка от краёв холста → прозрачный фон (чёрный внутри дизайна цел)
  ↓
поиск области под набор: эрозия от кремового канта + карта локальной дисперсии,
чтобы обойти иллюстрацию и волны
  ↓
Pillow впечатывает текст, подбирая кегль и разбивку на 1–3 строки
  ↓
512×512 lossless WebP → черновик → общий стикерпак и публичный ZIP
```

## Запуск

```bash
cp .env.example .env      # вписать TELEGRAM_BOT_TOKEN из @BotFather
python3 -m venv .venv && ./.venv/bin/pip install -e ".[dev]"
./.venv/bin/python -m pytest
./.venv/bin/python -m bot.main
```

Автозапуск:

```bash
cp deploy/com.katya.wndr-stickers.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.katya.wndr-stickers.plist
```

`deploy/com.katya.wndr-stickers.plist` и установленный LaunchAgent должны содержать `WNDR_RUNTIME_SANDBOX=1`; это маркер уже активной outer Seatbelt-песочницы.

## Как пользоваться

Прислать боту фразу — вернётся готовый стикер с кнопками «ещё вариант» и «в пак».

Премодерации нет: любой участник может добавить стикер в общий пак. Убирает
стикер его автор либо модератор клуба (`MODERATOR_USERNAMES` /
`MODERATOR_IDS` в `.env`; по умолчанию основатель и менеджер сообщества) —
остальным бот подсказывает, кому написать (`MODERATOR_CONTACT`). Голосования
за удаление больше нет (убрано 2026-08-12). Удаление необратимо — «передумал»
решается новой генерацией; файл и журнал действий сохраняются. Удаления
ограничены на пользователя и защищены коротким cooldown. Ядро пака трогает
только владелец.

Живые фразы: `убери из пака "фраза"`, `что в паке`.

Акцентное слово помечается звёздочками: `Это не *тантра*` — станет оранжевым.

| Команда | Что делает |
|---|---|
| `/style` | палитра и формы пака |
| `/quota` | сколько стикеров ещё доступно |
| `/pack` | ссылка на общий стикерпак |
| `/zip` | архив активного общего пака; приватные черновики не публикуются |
| `/history` | кто добавлял, убирал и возвращал стикеры |
| `/stats` | сводка (только владельцу) |

## Провайдеры картинок

`IMAGE_PROVIDER_CHAIN` в `.env` — список слева направо, с автоматическим
переходом к следующему при отказе:

| Провайдер | Модель | Что нужно |
|---|---|---|
| `codex` | `gpt-5.5` + built-in image_gen | подписка ChatGPT; изолированная песочница |
| `openrouter_gpt` | `openai/gpt-5-image` | кредиты на openrouter.ai |
| `openai` | `gpt-image-1` через Responses API | боевой `OPENAI_API_KEY` |
| `gemini` | `gemini-3-pro-image-preview` | ключ Gemini, есть бесплатный тариф |

Подписка ChatGPT не даёт прямого image-API, но Codex CLI может использовать
built-in `image_gen`. Бот копирует только OAuth-auth файл в одноразовый temp-home;
остальной `~/.codex` и настоящий home недоступны subprocess. Для прямого OpenAI
по-прежнему нужен отдельный платный ключ.

OpenRouter резервирует кредиты под `max_tokens`, поэтому при почти нулевом
балансе он отвечает `402` даже на маленький запрос.

## Стиль

Палитра — базовая тройка плюс кант; с v0.2 (решение Кати, 2026-08-12) добавлены редкие оттенки:

| Роль | HEX |
|---|---|
| акцент | `#CC3D11` |
| чёрный | `#0D0D0D` |
| кремовый | `#F2E2C8` |
| обводка | `#F7F3EA` |
| ржавый (оттенок, редкий) | `#992D0E` |
| терракота (оттенок, редкий) | `#E0764A` |
| песочный (оттенок, редкий) | `#D9BE93` |

Оттенки выпадают заметно реже базы (веса в `style.COMBOS`); приёмка `verify` принимает всю расширенную палитру. Стикеры бывают и без текста: «без текста костёр», — а на фразу, похожую на картинку, бот сам предложит вариант без надписи. Кавычки на стикерах не печатаются вовсе.

Стиль живёт в двух режимах вперемешку (`style.MODES`, выбор на каждый стикер): **classic** — «без рюшек и всего»: гладкие формы из `CLEAN_SHAPES`, плотность `plain` (заливка + один кант, никакого орнамента), look `clean` в промпте, базовая тройка цветов, без мотивов и автоакцента, детерминированная типографика; и **expressive** — разброс v0.2 (оттенки, богатые рамки, мотивы, автоакцент, росчерк). Веса 1:1, чтобы чередование было видно.

Правило роз: если в дизайне есть розы (мотив с розами, wreath-форма или «без текста розы»), чёрный `#0D0D0D` не используется нигде — заливка не бывает чёрной, линовка и тёмный текст/акцент идут ржавым `#992D0E`; приёмка `verify(forbid_black=True)` отклоняет такой стикер, если чёрных пикселей больше 5%. Технический чёрный фон генерации остаётся — он срезается при вырубке.

Source of truth по стилю: `docs/reference/WNDR-Sticker-Agent-v0.1.pdf` (sections 2/8/9) и машинный контракт `docs/reference/wndr-style-contract.v0.1.json`.

Типографика: плотный тяжёлый ретро-гротеск, центр, 1–3 строки, без light-шрифтов. Обводка 8–12px при 512px. Формы: скруглённый прямоугольник, wavy blob, starburst, молния/резаный параллелограмм, декоративный овал, стрелка/указатель, stamp/зубчатый край. Стрелки — каноническая форма v0.1.

Модель не пишет текст. Запрещены градиенты, 3D, gloss, drop shadow, фото/photorealism, не-чёрный фон генерации и любые цвета вне расширенной палитры (не больше четырёх в одном дизайне).

## Тесты

```bash
./.venv/bin/python -m pytest
```

Покрыто чистое ядро: транслит и версии, вырезание фона, поиск области под набор,
подбор кегля, техприёмка файла, валидация фраз, самоуправление и квоты. Сетевые вызовы в тестах
не участвуют.
