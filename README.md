# wndr-stickers

Отдельный Telegram-бот, который делает стикеры для сообщества WNDR в стиле пака.
Топология повторяет `english-tutor`: самостоятельный процесс под launchd плюс
Hermes-скилл сайдкаром.

## Суть подхода

Модель рисует **только плашку, без единой буквы**. Кириллицу впечатывает код
настоящим шрифтом. Два присланных гайда расходились именно здесь: первый просил
модель писать фразу самой, второй запрещал («на кириллице всегда брак»).
Выиграл второй — и правильно: теперь «объем» всегда с твёрдым знаком, «ё» не
подменяется на «е», а вопросительный знак стоит ровно тогда, когда он есть в
исходной фразе.

```
фраза
  ↓
модель рисует плашку на чёрном фоне, середина пустая
  ↓
заливка от краёв холста → прозрачный фон (чёрный внутри дизайна цел)
  ↓
поиск области под набор: эрозия от кремового канта + карта локальной дисперсии,
чтобы обойти иллюстрацию и волны
  ↓
Pillow впечатывает текст, подбирая кегль и разбивку на 1–3 строки
  ↓
512×512 lossless WebP → стикерпак и ZIP
```

## Запуск

```bash
cp .env.example .env      # вписать TELEGRAM_BOT_TOKEN из @BotFather
python3 -m venv .venv && ./.venv/bin/pip install -e ".[dev]"
./.venv/bin/python -m pytest
./.venv/bin/python -m bot.main
```

Автозапуск:

```bash
cp deploy/com.katya.wndr-stickers.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.katya.wndr-stickers.plist
```

## Как пользоваться

Прислать боту фразу — вернётся готовый стикер с кнопками «ещё вариант» и «в пак».

Акцентное слово помечается звёздочками: `Это не *тантра*` — станет оранжевым.

| Команда | Что делает |
|---|---|
| `/style` | палитра и формы пака |
| `/quota` | сколько стикеров ещё доступно |
| `/pack` | ссылка на общий стикерпак |
| `/zip` | архив со всеми версиями |
| `/stats` | сводка (только владельцу) |

## Провайдеры картинок

`IMAGE_PROVIDER_CHAIN` в `.env` — список слева направо, с автоматическим
переходом к следующему при отказе:

| Провайдер | Модель | Что нужно |
|---|---|---|
| `openrouter_gpt` | `openai/gpt-5-image` | кредиты на openrouter.ai |
| `openai` | `gpt-image-1` через Responses API | боевой `OPENAI_API_KEY` |
| `gemini` | `gemini-3-pro-image-preview` | ключ Gemini, есть бесплатный тариф |

Подписка ChatGPT доступа к image-API не даёт: в `~/.codex/auth.json` лежит OAuth,
а `OPENAI_API_KEY: null`. Для прямого OpenAI нужен отдельный платный ключ.

OpenRouter резервирует кредиты под `max_tokens`, поэтому при почти нулевом
балансе он отвечает `402` даже на маленький запрос.

## Версии и утверждённое

Имена файлов — латиница, kebab-case, версия в конце:
`ya-prinoshu-ves-svoy-obem-v1.webp`. Утверждённое **никогда не перезаписывается**,
новое решение уходит следующей версией.

## Стиль

Палитра ровно три цвета плюс кант:

| Роль | HEX |
|---|---|
| акцент | `#CC3D11` |
| чёрный | `#0D0D0D` |
| кремовый | `#F2E2C8` |
| обводка | `#F7F3EA` |

Типографика доминирует, иллюстрация лишь усиливает смысл. Стрелки выключены —
свежий хендофф их запретил, хотя на старом эталонном листе они ещё встречаются;
включаются флагом `ALLOW_ARROW_SHAPES=true`.

## Тесты

```bash
./.venv/bin/python -m pytest
```

Покрыто чистое ядро: транслит и версии, вырезание фона, поиск области под набор,
подбор кегля, техприёмка файла, модерация фраз, квоты. Сетевые вызовы в тестах
не участвуют.
