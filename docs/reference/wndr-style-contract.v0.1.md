## Contract

- Palette is exact: accent `#CC3D11`, black `#0D0D0D`, cream `#F2E2C8`, outline `#F7F3EA`.
- Text plates use exactly two base colours; a third colour appears only as an accent on 1–3 words.
- Outer die-cut outline is warm cream-white, 8–12 px at 512 px. It must separate the sticker from both light and dark chat backgrounds.
- Typography is dense, heavy, retro grotesque / 1970s signage; centered; 1–3 lines; no light fonts.
- The image model never writes the user phrase or any text. Cyrillic/text is rendered later by code.
- Allowed plate forms: rounded rectangle, wavy blob/speech blob, starburst, lightning/cut parallelogram, decorative oval, arrow/pointer badge, stamp/toothed edge.
- Illustration stickers use vintage botanical/engraving style, flat fills, heavy black linework and the same palette.
- Generation background is plain solid black; black must touch all four canvas corners for cut-out.
- Banned: gradients, 3D, gloss, drop shadow, photorealism/photo, more than three colours, non-black generation background, model-generated text/letters/numbers/captions/watermarks/signatures.
